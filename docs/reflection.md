# Reflection

In this project I learned how to use GitHub in project planning and how to handle and organize a project. This was done as I learned the different aspects like creating issues and making commits from different branches, as well as creating pull requests and merging all the edits into the main branch. 
This is beneficial when it comes to planning projects since creating issues helps plan specific tasks and organize a project.

I enjoyed discovering the different tools and features like making the commits and merging the different section, but it was challenging to figure out why the separate branches were needed and how the pull requests work to add them back to the main.
If I had more time, I would improve my work by adding more detailed information and learning how to further improve the styles and designs of the content.
